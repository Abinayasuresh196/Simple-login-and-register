🔐 Secure User Authentication System

This project was developed as Task-01 of my Full Stack Development Internship at Prodigy InfoTech.
The goal of this task was to build a secure user authentication system following real-world web application practices.

📌 Task Overview

The Secure User Authentication System allows users to:

✅ Register for a new account

🔑 Log in securely

🔒 Access protected routes only after successful authentication

🛠️ Technologies Used
Frontend

HTML

CSS

JavaScript

Backend

Node.js

Express.js

Database

MongoDB

✨ Key Features

Secure user registration and login functionality

Password handling using secure authentication practices

Session-based authentication

Protected routes accessible only to authenticated users

Backend validation and proper error handling

📚 What I Learned

Implementing authentication flows in full stack applications

Connecting frontend forms with backend APIs

Managing user sessions and protected routes

Storing and retrieving user data securely using MongoDB

Understanding real-world authentication mechanisms
